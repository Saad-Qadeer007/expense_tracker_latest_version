# 💸 Expense Tracker

A modern, feature-rich **Expense Tracker** built with **Flutter** that helps users manage their personal finances efficiently. The application provides an intuitive interface for tracking income and expenses, filtering transactions, visualizing spending patterns, and generating monthly reports.

Designed with clean architecture, responsive UI, and reusable components, this project focuses on delivering a smooth and user-friendly experience.

---

## ✨ Features

### 💰 Transaction Management
- Add income and expense transactions
- Edit existing transactions
- Delete transactions with confirmation dialog
- Automatic balance calculation
- Optional notes for every transaction

### 🔍 Search & Filtering
- Search transactions by title
- Filter by category
- Filter by date:
  - Today
  - This Week
  - This Month
  - This Year
- Combine multiple filters simultaneously

### 📊 Analytics
- Monthly expense breakdown
- Interactive Pie Chart
- Monthly financial report
- Category-wise expense summary

### 🎨 User Experience
- Responsive UI
- Custom reusable widgets
- Smooth animations
- Consistent SnackBars
- Form validation
- Clean Material Design
- Confirmation dialogs for destructive actions

### 💾 Data Storage
- Local persistence using SharedPreferences
- Automatically saves all transactions
- Restores data when the app is reopened

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/Saad-Qadeer007/expense_tracker.git
```

## Navigate to the project

```bash
cd expense_tracker
```

## Install dependencies

```bash
flutter pub get
```

## Run the application

```bash
flutter run
```
